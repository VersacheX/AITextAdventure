### data_mgmt_screen
Data management screen is a user interface component that allows users to manage and manipulate data within the application. 
It provides functionalities such as viewing and filtering, and organizing data entries. 
The screen is designed to be intuitive and user-friendly.
It's purpose is provide lookup information to provide data to an ai for review
Integrates with \AITextAdventureAPI\ai_fastapi_server\story_suggestion_server.py view \AITextAdventureAPI\ai_fastapi_server\README.md
